# Valentine's Day Surprise 💝
A personal web project created to share a special message for Valentine's Day.

## ✨ Highlights
* **Interactive Messages:** Hidden notes and scrolling text.
* **Atmosphere:** Integrated background music for a complete experience.
* **Responsive Design:** Styled to look great on both mobile and desktop.

## 🎵 How to View
1. Open `index.html` in your browser.
2. Make sure your volume is up for the background music!
